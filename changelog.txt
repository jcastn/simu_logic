v0.17.6 - Replaced CMake by Makefile

Changes : 
- Replaced CMakeLists.txt file by a Makefile.
- Removed simu_logic.sh file. 
- Added 'make' commands :
  - 'make' / 'make all'  : compile the app in default mode.
  - 'make re' : delete all build files and recompile the app in default mode.
  - 'make clean' : delete all build files
  - 'make fclean' : delete all build files and app binary.
  - 'make debug' : delete all build files and  recompile the app in debug mode. 
- Reworked the #include calls : they no longer contain the path to the header files.
